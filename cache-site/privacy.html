LeetHint privacy policy

Last updated 7 November 2026

LeetHint is a Chrome extension that gives progressive hints, a verified solution and mock interviews for LeetCode problems. It has no accounts, shows no ads and sells nothing. This page lists exactly what leaves your browser and what stays on it.

What is sent, and where

DataSent toWhy, and how long it is kept
The public LeetCode problem you open (title, statement, tags, starter code) LeetHint's server, and LeetHint's static hint site To fetch or generate hints. Generated hints are cached for every user of that problem; the problem text is public.
An anonymous install ID (a random number created when you install LeetHint) LeetHint's server Fair-use limits and free-trial counts. It is not linked to your name, email or LeetCode account. Daily and weekly counters are kept for a few weeks.
Code you send to Fix, with LeetCode's error message LeetHint's server, then an AI provider To debug it. Not stored by LeetHint.
Mock interview text (what you and the interviewer said, your editor code) LeetHint's server, then an AI provider To run the interview and grade it. Not stored by LeetHint.
A "Report wrong hint" (problem, reason, your optional note) LeetHint's server So the hint can be checked and regenerated. Kept until it has been reviewed.
Your voice, during a mock interview with the microphone on Google, through Chrome's built-in speech recognition Chrome turns speech into text; LeetHint receives only the text. Google's privacy policy applies to this.

The AI providers LeetHint's server uses (Groq, Google Gemini, Cloudflare Workers AI) receive only the prompt built from the data above, never your install ID. Their own policies apply to how they handle requests.

Your own API key

If you add your own free AI key in Settings, it is stored only in your browser and sent only to the provider you picked (Google Gemini, Groq or OpenRouter). Requests made with it go straight from your browser to that provider, and LeetHint's server never sees the key or those answers.

What stays on your computer

Everything else is kept in your browser's extension storage (chrome.storage.local) and never uploaded: your stats and scores, revision queue, streaks, pattern guesses, confidence log, interview history, saved hints, settings and your own API key. Removing the extension deletes all of it.

What LeetHint never does

  • It does not read your LeetCode account, submissions history or cookies, and never changes the LeetCode page.
  • It does not track the other sites you visit; it only runs on leetcode.com/problems/*.
  • It does not sell or share data with advertisers or data brokers.

Contact

Questions or a deletion request (quote your install ID from Settings): github.com/Yug912/LeetHint/issues.
